# AI 书房 · AI Reading Room

与 AI 一起读书、思考，让阅读所得融入生活。

[English](README.en.md)

DSH 桌面插件，侧栏入口「AI 书房」，内置阅读伙伴「书虫」。包名 `dsh-ai-reading-room`，当前版本为 0.5.2，预构建发行包见 Releases 页面，使用 MIT 许可证开源。

## 安装

要求 DSH 0.2.2-rc.2 或兼容的 0.2.x 版本、Node.js 22.13.0 及以上。当前实际验证基线为 DSH Desktop 0.2.2-rc.2。

推荐使用预构建发行包。在 DSH 的「插件 → 添加插件」中输入：

```text
https://github.com/yubudong/dsh-ai-reading-room/releases/download/v0.5.2/dsh-ai-reading-room-0.5.2.tgz
```

也可以使用 CLI，将 `<profile>` 替换为你的配置名称：

```sh
dsh plugin --profile <profile> add https://github.com/yubudong/dsh-ai-reading-room/releases/download/v0.5.2/dsh-ai-reading-room-0.5.2.tgz
```

从 GitHub 源码安装也可用，仓库已包含构建产物，不要求安装时执行构建脚本：

```sh
dsh plugin --profile <profile> add github:yubudong/dsh-ai-reading-room
```

安装后刷新 DSH 页面；若仍保留旧界面，重启 DSH。插件尚未发布 npm；市场收录以维护者合并后的实际状态为准。

## 使用

在 DSH 插件管理中添加本地插件目录并启用。左侧进入 AI 书房，导入 EPUB、PDF、TXT 或 Markdown。点开书籍阅读，选中文字后右键，可划线、写感悟、记疑问或向书虫提问；普通选字不会自动弹出色板。右侧切换笔记与阅读历程。

书虫提供自由讨论、狩猎法（发现线索）、费曼法（讲给书虫听）、辩论法（检验观点）。打开书就能直接输入消息，无需填写目标、选择阶段或点击开始。选择方法不会自动发起模型请求；可以输入自己的问题，或点击“陪我读当前内容”。方法可在同一段讨论中切换，问题在阅读中逐渐形成，旧目标与记录保留供回看。

拖动书虫侧栏的左边缘调整宽度；聚焦分隔线后可用左右键微调，双击或 Enter 恢复默认宽度。右上角可展开、恢复阅读布局或收起，顶部书虫按钮可重新打开。模型选择和刷新列表内置于输入框底部，当前讨论的模型独立保存，不改变 DSH 全局默认。Enter 发送，Shift+Enter 换行，中文输入法组合输入不会误发送。

书虫通过 DSH 原生会话使用已配置的模型；相关选段或章节摘录会发送给对应服务。笔记与阅读无需模型在线。书虫形象采用青绿小书虫、圆眼镜与打开的书，资源随插件离线加载。

设置中可以选择回复语言、模型和阅读字号，导出学习资产或含原书的 ZIP 备份。恢复会替换当前书房记录，预先展示数量并在本地自动保存旧数据快照。模型凭据不在备份中。导入的原生会话 ID 会清除，历史文字保留，下一次发送建立新会话。

## 0.5.2 功能

- 正文选区与已有标注仅通过右键打开颜色、下划线、笔记和移除菜单；支持按书籍隔离的最近50步撤销/重做。Mac 使用 ⌘Z/⌘⇧Z，Windows 使用 Ctrl+Z/Ctrl+Shift+Z，输入框保留自身的文字撤销。
- 专注阅读、左右栏调宽、文字锚点进度、精确原文引用和跳转后返回。
- 我的痕迹支持书籍、颜色、类型、日期、未写感想与待解疑问筛选，选中记录可单独导出。
- 自由聊与读书方法论双入口，方法介绍、可编辑提示词、个人版本、收藏与历史快照。
- 简短/适中/深入回复偏好；主动发起、可编辑的阅读回顾，区分用户表达与 AI 建议。小行动只存草稿，不创建待办或提醒。
- 本版本通过64组逻辑和数据回归测试；真实页面操作、明暗主题及完整在线模型流程尚未完成全面目视验收，详见验证记录。

## 书库与方法使用说明

阅读伙伴已改名为「书虫 / Bookworm」。导入完成后可以直接开始阅读；支持批量扫描含子目录的文件夹，或关联现有目录而不重复复制。主书库位置可在设置中更改，迁移先复制校验、保留旧文件。旧 EPUB 会优先修复正式导航目录，并保持正文和批注位置。

方法库支持完整提示词预览、本次编辑、个人方法、排序、停用和 JSON 导入导出。首次选择方法默认展开提示词，熟悉后可收起或隐藏；选择方法不调用模型。每轮保留实际提示词版本。

顶部“使用说明”提供可搜索的双语手册、快捷键速查和书虫操作帮助。快捷键只在正文聚焦时生效，支持本机修改与恢复默认，不影响聊天、笔记编辑和输入法组合输入。

- [中文使用说明书](docs/USER_GUIDE.zh.md)
- [English user guide](docs/USER_GUIDE.en.md)

旧版原书升级后复制到数据目录下的 `library/`（可更改），原 `books/` 副本保留作为回退来源；解析缓存仍在 `books/`。学习资产备份格式升级为版本 2，新版本可以读取此前的版本 1 备份，旧插件不能承诺读取新版备份。

## 数据

结构化记录存入 DSH 的 `ai_reading_room_v1` 数据单元。原书默认保存到 DSH home 下的 `ai-reading-room/library`（设置中可更改），解析文件保存在 `ai-reading-room/books`，文件按 SHA-256 标识。源文件不修改。备份前快照在 `ai-reading-room/backups`。

划线与笔记保存具体文件哈希、章节 ID、文本范围、原文及日期。普通笔记修订带版本保护；删除进入可恢复回收站。界面草稿只保存在浏览器本地，不属于服务器备份。

## 当前边界

- EPUB 使用清理后的重排阅读，去除脚本、原始 CSS 和远程图片；支持常见文字、内嵌栅格图片和书内锚点。固定版式、音视频、复杂数学与竖排未适配。
- PDF 提供原版、可选择的文字层与文字视图；选区保存文字范围和页面坐标。扫描版只看原版和记页码笔记，尚无 OCR。
- TXT 支持 UTF-8、GB18030 和 Big5；Markdown 本地图片不自动复制，远程图片不加载。
- 单本上限 64 MiB；PDF 上限 2500 页；ZIP 解压合计上限 192 MiB。大书库备份需控制规模，当前还没有分卷备份。
- 检索为大小写不敏感的字面匹配，最多返回 100 个命中；尚无语义或跨语言向量检索。
- 尚不包含 MOBI/AZW3 转换、跨书主题、生活实践模块、提醒、云同步。
- 引用链接优先定位已核对的具体原文片段，旧讨论可能只回到章节；引用不能自动证明 AI 解释正确。请回到原文核对。
- 兼容验证基线为 DSH 0.2.2-rc.2；其他版本需要另行验证。

## 开发

使用 Node 22.13.0+ 与 pnpm。依赖不需要运行安装脚本。

```sh
pnpm install --ignore-scripts
pnpm run build
pnpm test
```

源代码在 `src/host` 与 `src/client`。构建产物 `index.js`、版本化 Host 文件、`client.js` 和 PDF worker 随包交付。构建不修改 DSH 安装目录。数据与个人图书不得提交到仓库。
