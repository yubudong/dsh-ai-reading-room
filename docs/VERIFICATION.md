# 验证记录 · 0.1.0

日期：2026-11-25。目标环境：DSH Desktop 0.2.2-rc.2，macOS arm64。验证以电脑端为准。

## 自动化检查

运行 `pnpm test`，覆盖下列九组场景：

1. EPUB 按 spine 顺序读取，解析书名和作者，保留中英文及实体字符，移除脚本、事件处理器和远程图片。
2. TXT 与 Markdown 的中英文正文提取。
3. PDF 在不依赖原生画布的情况下提取文字。
4. 损坏 PDF、不安全 ZIP 路径和未支持格式的失败结果。
5. 相同文件去重、选区原文校验、重复保存幂等、旧 revision 冲突、修订历史、回收站恢复和存储重新打开。
6. 阅读练习阶段、暂停状态、可见讨论消息在备份恢复后保留；导入时清除原生会话 ID；恢复前保存快照。
7. 未知备份版本和原书哈希不匹配被拒绝。
8. 原生会话投影忽略无关事件，只提取可见用户问题和已提交助手消息。
9. UI 的 Host 请求与 Agent 工具共用业务规则，对缺失书籍返回一致错误；Agent 不能执行备份覆盖恢复。

另执行构建、Host/Client 语法检查和实际发布包内容检查。测试使用专门构造的材料，不读取用户私人图书。

## 当前运行环境检查

- 插件通过 DSH 插件管理器安装，应用结果为 applied。
- 运行时检查确认 `ai-reading-room` 侧栏入口和同 key 主面板登记。
- 通过实际 `reading_room` 工具导入原创示例材料，并在插件移除/重新安装后确认书库仍保留。
- 在示例材料中建立费曼法练习，通过当前 DSH 的默认模型配置建立书灵原生会话。没有为测试发送模型消息，未消耗生成额度。
- 原文通过实际工具可以读取，书库状态与练习通过实际工具可以查询。

## UI/UX 自查

当前会话没有浏览器控制工具，也没有可调用的子代理启动工具，因此由主代理完成源码层面的 UI/UX 自查。

检查了入口、导入后打开书籍、选区保存、练习暂停/继续、草稿保留、错误反馈、备份预览、焦点循环、宿主主题 token 和本地化文案。修正了跨段落划线破坏正文结构、回顾按钮含义不明确、普通操作错误未翻译、记录来源未标识等问题。

没有启动替代服务器，没有以模拟页面代替真实插件，也没有启动新的浏览器获取截图。

## 尚未完成的运行验收

目前无法目视验证当前 DSH 内的布局、明暗主题、图标显示、PDF 文字层选区和鼠标/键盘操作；完整的用户发送消息 → 模型回复 → 收入笔记链路尚未在真实界面操作。原生会话创建成功不能等同于整个问答流程已验收。

安装后建议刷新现有 DSH 页面。Host 源码后续更新需要按 DSH 的加载机制重载；如果页面或后台仍保留旧构建，重启 DSH 后使用。

OCR、MOBI/AZW3、跨书主题、实践看板、提醒和云同步属于后续版本，不包含在此次完成声明中。
