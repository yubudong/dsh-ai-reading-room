## 0.5.1 选区色板回归修复

- 用户确认选中文字后没有浮动色板。当前阅读 EPUB 的正文带开头换行缩进，原先按完整 HTML 文档解析会丢弃开头空白，使严格选区偏移核对失败；改为在惰性文档内按片段解析，保留开头空白。
- 同时修正选区仅依赖正文元素 mouseup 的覆盖问题，以及正文重绘、自动位置恢复未避让原生选区的情况。
- 改为文档级 pointerup 与 selectionchange 监听，只处理从本阅读区开始或结束的选区，允许在正文边缘松开鼠标；键盘选字也使用同一捕获链路。
- 标注绘制只在正文或实际标注外观变化时重建，不因字体、跳转、普通笔记元数据或数组刷新清除选区。实际重绘时保存和恢复原生选区。
- 选字拖动、已有原生选区或色板打开期间，自动定位和定位采样暂停；明确跳转先清除旧选区。
- 增加原文与 DOM 空白差异映射，保存和绘制分别核对坐标，不改动原章节文本或旧标注。模糊的重复文本不生成错位标注。
- PDF 同步使用跨元素的选字结束监听，仍保持原有文本核对和矩形标注。
- 增加六组普通选区、段落空白、不可见字符、重复短句及绘制失效条件测试。没有浏览器控制工具，本次未宣称已目视重现用户页面或实际鼠标拖动验收。

## 自动化检查

运行 `pnpm test`，覆盖下列九组场景：

1. EPUB 按 spine 顺序读取，解析书名和作者，保留中英文及实体字符，移除脚本、事件处理器和远程图片。
2. TXT 与 Markdown 的中英文正文提取。
3. PDF 在不依赖原生画布的情况下提取文字。
4. 损坏 PDF、不安全 ZIP 路径和未支持格式的失败结果。
5. 相同文件去重、选区原文校验、重复保存幂等、旧 revision 冲突、修订历史、回收站恢复和存储重新打开。
6. 阅读练习阶段、暂停状态、可见讨论消息在备份恢复后保留；导入时清除原生会话 ID；恢复前保存快照。
7. 未知备份版本和原书哈希不匹配被拒绝。
8. 原生会话投影忽略无关事件，只提取可见用户问题和已提交助手消息。
9. UI 的 Host 请求与 Agent 工具共用业务规则，对缺失书籍返回一致错误；Agent 不能执行备份覆盖恢复。

另执行构建、Host/Client 语法检查和实际发布包内容检查。测试使用专门构造的材料，不读取用户私人图书。
